### 📊 Опыт работы — 4 месяца


Работаю по трудовому договору (ИП Валиева Л.Ф., удалённо) в рамках годовой программы развития Junior-разработчиков: задачи на Angular, наставник, код-ревью. Программа рассчитана на 12 месяцев (май 2026 – май 2027). Все 30 заданий закрыл досрочно, примерно за 4 месяца. Сейчас переведён в группу коммерческой разработки.

Задачи в проектах компании:
• Брал задачи с Kanban-доски (Taiga) в двух проектах компании
• Код сдавал через pull request, после ревью задачу мёржили в проект

Учебный проект на Angular (одно приложение, развивалось от задания к заданию; каждое задание — отдельный pull request с код-ревью наставника):
• Вёрстка по макетам Figma, control flow (@for, @if), двусторонняя привязка данных, hover-анимации
• Сервисы состояния на RxJS (BehaviorSubject + asObservable, async pipe): toast-уведомления, глобальный лоадер с overlay, generic-сервис для localStorage
• Работа с REST API: API-слой отделён от сервиса состояния, обработка ошибок через catchError и finalize, синхронизация данных с localStorage
• Smart/dumb компоненты (@Input/@Output), реактивные формы с валидацией, фильтрация списка на debounceTime, distinctUntilChanged и combineLatest
• Роутинг: lazy loading всех маршрутов, resolvers, AuthGuard и AdminGuard (доступ по роли пользователя)
• Авторизация на JWT (DummyJSON API): страница логина, AuthService, interceptor для подстановки токена в запросы
• HTTP-интерсепторы: логирование запросов (метод, URL, статус, время выполнения) и глобальная обработка 5xx-ошибок
• Фича «Посты» — полный CRUD на PrimeNG: таблица с серверной пагинацией, контекстное меню, skeleton при загрузке, модальное окно редактирования, детальная страница через resolver
• PrimeNG: переключение тем (Aura, Lara, Nora) и светлого/тёмного режима с сохранением выбора; Font Awesome; переопределение стилей через :host и ::ng-deep
• Кастомные pipes (склонение слов по числу, форматирование телефона в 4 режимах) и атрибутные директивы на HostListener и Renderer2
• Dependency Injection: InjectionToken для конфигурации приложения и формата дат
• Change Detection (OnPush), Angular Signals (signal, computed, effect, toSignal)
• Настройка ESLint и Prettier: flat config, отдельные правила для TypeScript и HTML-шаблонов
• Рефакторинг приложения под feature-based архитектуру (core / shared / features) с обоснованием решений в описании PR

До Angular прошёл блок по HTML, CSS и JavaScript.
