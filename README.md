Программа по договору рассчитана на год, с мая 2026 по май 2027: работа с наставником, код-ревью, задачи по Angular. Все 30 заданий программы я закрыл досрочно, примерно за 4 месяца. Сейчас меня перевели в группу коммерческой разработки.

Учебный проект на Angular. Одно приложение, которое я развивал от задания к заданию. Каждое задание сдавал через pull request, и его проверял наставник на код-ревью.

Вёрстка по макетам Figma, новый control flow (@for, @if), двусторонняя привязка данных, анимации при наведении.
Сервисы состояния на RxJS: BehaviorSubject + asObservable(), данные в шаблон через async pipe. Так сделаны toast-уведомления, глобальный лоадер с overlay и generic-сервис для localStorage.
Работа с REST API: слой API отделён от сервиса состояния, ошибки обрабатываются через catchError и finalize, данные синхронизируются с localStorage.
Паттерн smart/dumb (@Input/@Output), реактивные формы с валидацией, фильтрация списка через debounceTime, distinctUntilChanged и combineLatest.
Роутинг: lazy loading всех маршрутов, resolver, AuthGuard и AdminGuard (доступ по роли пользователя).
Авторизация на JWT (DummyJSON API): страница логина, AuthService, interceptor, который подставляет токен в запросы, обработка истечения сессии [?].
HTTP-интерсепторы: логирование запросов (метод, URL, статус, время выполнения) и глобальная обработка 5xx-ошибок через сервис уведомлений.
Фича «Посты», полный CRUD на PrimeNG: p-table с серверной пагинацией, контекстное меню, skeleton на время загрузки, модалка редактирования, детальная страница через resolver.
PrimeNG: переключение тем Aura, Lara и Nora, светлый и тёмный режим с сохранением выбора. Font Awesome. Переопределение стилей через :host и ::ng-deep.
Кастомные pipes: склонение слов по числу, форматирование телефона в 4 режимах. Атрибутные директивы на HostListener и Renderer2, одна из них с настройкой через @Input.
DI: InjectionToken для конфигурации приложения и для формата дат (DATE_PIPE_DEFAULT_OPTIONS).
Change Detection (OnPush), Angular Signals: signal, computed, effect, toSignal.
Настройка ESLint и Prettier: flat config, отдельные правила для TS и для HTML-шаблонов.
Рефакторинг архитектуры приложения под feature-based структуру (core / shared / features). Выбор решений обосновывал в описании PR.
Задачи в проектах компании. Брал задачи с Kanban-доски в Taiga по проектам
До Angular прошёл блок по HTML, CSS и JavaScript
